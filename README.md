# تحويل

> محوّل وضاغط صور عربي يعمل محليًا داخل المتصفح.

## المزايا

- تحويل PNG وJPG وWebP إلى WebP أو JPG أو PNG.
- اختيار جودة الضغط وأقصى عرض للصورة.
- معالجة حتى 30 صورة دفعة واحدة.
- تنزيل جميع الصور الناتجة في ملف ZIP.
- واجهة عربية RTL متجاوبة.
- لا تُرفع الصور إلى خادم؛ كل المعالجة تحدث على جهاز المستخدم.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم في النسخة الأولى:

1. نزّل المستودع.
2. افتح `index.html` في متصفح حديث.
3. اختر الصور ثم اضبط الإعدادات واضغط «تحويل الصور».

> يحتاج تنزيل ZIP إلى اتصال إنترنت في أول تشغيل لتحميل مكتبة JSZip من CDN.

## التقنية

- HTML وCSS وJavaScript.
- Canvas API لتحويل الصور وضبطها.
- JSZip لإنشاء ملف ZIP.
- معالجة محلية مع `createImageBitmap` و`canvas.toBlob`.
